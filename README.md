# Посмотри в окно

Учебный проект от Яндекс Практикума — интерактивное веб-приложение для просмотра и поиска видео. Пользователь может листать карточки с видео, искать ролики по параметрам и просматривать их в большом плеере.

В рамках данной проектной работы была выполнена **стилизация интерфейса (CSS)** для уже готовой HTML-разметки и логики на JavaScript. Основная задача — привести внешний вид приложения в точное соответствие с дизайн-макетом, сохранив при этом всю исходную функциональность.

## 🛠 Технологии и особенности реализации

- **HTML5** — семантическая разметка (предоставлена в заготовке).
- **CSS3** — основная работа велась здесь:
  - Построение лейаута с помощью **Flexbox**.
  - Стилизация кастомных элементов форм (собственные чекбоксы, скрытие дефолтных элементов через `.visually-hidden`).
  - Работа с состояниями элементов (`:hover`, `:active`, `:focus-visible`, `:checked`).
  - Ограничение и обрезка текста (`line-clamp`, `text-overflow: ellipsis`).
  - Использование `object-fit` для корректного отображения видео и картинок.
  - Стилизация полосы прокрутки (скроллбара) и прелоадеров.
- **JavaScript** — обеспечивает динамику приложения (загрузку карточек, поиск, смену видео). Логика была предоставлена и не изменялась.
- **БЭМ** — именование CSS-классов.

## 🚀 Функциональность приложения

- Загрузка списка видеокарточек с внешнего сервера.
- Переключение основного видео при клике на миниатюру из списка.
- Поиск видео по заданным параметрам через форму.
- Подгрузка дополнительных карточек по кнопке «Показать ещё».
- Отображение состояний загрузки (прелоадеры) и ошибок.
